# PROJECT_ENTRY.md Instructions

## Format
Three flowing narrative paragraphs, no bullet points, semicolons, or emdashes. Max 45 words per paragraph.

## Structure

**Paragraph 1: The Build**
Start with "Built" or similar verb. Describe the core product, tech stack, and user-facing functionality. Focus on what users see and do.

**Paragraph 2: The Architecture**
Start with "Architected" or similar verb. Explain the technical solution, systems design, performance optimizations, and constraints solved. Include metrics (API reduction %, response times, concurrency, etc.).

**Paragraph 3: The Engineering**
Start with "Built" or "Engineered". Cover data pipelines, deployment infrastructure, performance achievements, and component library choices. End with full-stack narrative.

## Tips
- Use active verbs: Built, Architected, Engineered, Implemented, Optimized, Deployed
- Include 1-2 quantified metrics per section (85% reduction, 100K+ trips, sub-second response)
- Weave tech stack naturally into sentences, not as lists
- Connect technical depth to user impact
- Read like a story: what you made → how you solved it → how you deployed it
- Keep keywords dense for ATS scanning
